# Vlossom

Vue 3 UI 컴포넌트 라이브러리.

이 사이트의 컴포넌트 문서는 **따로 작성한 문서가 아닙니다.** 라이브러리 소스의 `README.ko.md` 파일이 그대로 페이지가 됩니다.

- 사람이 읽는 문서 = GitHub에서 보는 README = `vlossom-mcp`가 AI 에이전트에게 주는 지식
- 예제 코드는 그 자리에서 **실제로 동작**합니다
- 컴포넌트 페이지 상단의 **Color scheme** 바에서 색을 고르면 그 페이지의 모든 데모에 즉시 적용됩니다
- 오른쪽 위 테마 토글은 문서와 컴포넌트에 함께 적용됩니다
