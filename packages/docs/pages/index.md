# Vlossom

Vue 3 UI component library.

The component docs on this site are **not written separately.** Each `README.md` in the library source *is* the page.

- What a human reads = what GitHub shows = what `vlossom-mcp` feeds to AI agents
- Every example runs **for real**, right where it is written
- The **Color scheme** bar at the top of a component page recolors all its demos at once
- The theme toggle in the top right applies to both the docs and the components
